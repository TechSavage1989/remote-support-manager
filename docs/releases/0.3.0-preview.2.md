# 0.3.0-preview.2

The same features as 0.3.0-preview.1, now **code-signed** with Azure Artifact Signing.

- Every program in the package is signed: the server setup, the server, the viewer and its installer, the client and the update tool. The installers contain signed copies of the programs.
- Windows shows the publisher instead of "Unknown publisher", and SmartScreen and antivirus tools see a trusted signature.
- Releases are never published unsigned from now on.

## Not verified yet

The installer, the Windows service, Tailscale Funnel and Let's Encrypt have not been run on a real Windows PC or a real internet connection yet. See docs/TESTING.md section 2a.
