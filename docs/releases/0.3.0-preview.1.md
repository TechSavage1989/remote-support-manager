# 0.3.0-preview.1

Works over the internet, and the server installs with no command line. Unsigned executables; use test PCs and made-up data.

## New

- **RemoteSupportServerSetup.exe**: double-click, approve the Windows administrator prompt, and the server runs in the background as a Windows service. Remove it from Settings > Apps (it asks whether to keep your data).
- **Setup page in your browser** (Start menu → *Remote Support Manager Server setup*): create the first administrator, set your organisation name and choose how customers reach the server. It only opens on the server itself.
- **Over the internet, free**, three ways:
  - **Tailscale Funnel**: no router changes; your server gets a free `name.ts.net` address. The setup page turns Funnel on for you.
  - **Your own name and router**: the server gets and renews a free Let's Encrypt certificate itself. Only port 443 needs forwarding.
  - **Cloudflare Tunnel**: point it at the server, which then trusts it for client addresses.
- Over the internet, clients and the viewer trust the public certificate, so there's no fingerprint to copy.
- The setup page shows whether the certificate or Funnel is ready, and the link to open if Tailscale asks you to allow Funnel.

## Not verified yet

The installer, the Windows service, Tailscale Funnel and Let's Encrypt have not been run on a real Windows PC or a real internet connection yet. The setup page and server switching are covered by automated tests. See docs/TESTING.md section 2a.
