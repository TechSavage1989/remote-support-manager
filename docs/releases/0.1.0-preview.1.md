# 0.1.0-preview.1

First test build. Unsigned executables; use test VMs and made-up data.

- Self-hosted server with web console, MFA, client/site/device inventory, enrollment tokens, revocation and audit log.
- Windows agent with consent prompt, support code, amber session bar, tray icon, per-user install and uninstall.
- Native Windows viewer: fit, actual size, full screen, monitors, keyboard shortcut capture, special keys.
- File manager with folders, resume, conflict choices and integrity checks.
- Clipboard sync for text, rich text and images.
- Signed, user-approved updates with rollback (needs a signing key built in; this preview has none, so updates are off).
