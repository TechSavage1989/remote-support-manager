# 0.2.0-preview.1

Second test build, and the first one published (0.1.0-preview.1 was never released; its notes are kept for history). Unsigned executables; use test VMs and made-up data.

## New: session types and packaging

- **One-time (portable)**: the customer downloads the program, types a 6-digit code and agrees. Nothing is installed; it closes after the session and the server forgets the PC.
- **Support session**: installed for the customer's user account after they agree once. Reconnect as often as needed; **Close support session** in the console uninstalls it from their PC.
- **Unattended access** (administrators only): installed machine-wide as a Windows service with UAC approval. Works at the sign-in and lock screens, supports Ctrl+Alt+Del, shows a tray notice to every user and the amber bar in every session. Removing the device uninstalls it.
- **Attended agent** can now also be installed from a console download.
- The customer can untick control, clipboard and file transfer when agreeing; the server never grants more.
- **Viewer installer** (per user, Start menu, Settings > Apps) next to the portable viewer, both downloadable from the console.
- The server serves the `downloads` folder next to it; new `serve` options `--downloads` and `--public-url`.

## From 0.1 (first build)

- Self-hosted server with web console, MFA, client/site/device inventory, audit log.
- Consent prompt with support code, amber session bar, tray icon.
- Native Windows viewer: fit, actual size, full screen, monitors, keyboard shortcut capture, special keys.
- File manager with folders, resume, conflict choices and integrity checks; clipboard sync for text, rich text and images.
- Signed, user-approved updates with rollback (needs a signing key built in; this preview has none, so updates are off).

## Not verified yet

The Windows windows, service and uninstall paths build and the shared logic passes the automated tests, but they have not been run on a real Windows PC yet. See DEVELOPMENT_HANDOFF.md.
